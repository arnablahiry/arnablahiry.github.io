AstroVOX

AstroVOX#

AstroVOX is a desktop visualization application for volumetric data cubes commonly encountered in astronomy and astrophysics: interferometric and single-dish spectral-line cubes (HI, CO), integral-field spectroscopy data, and simulated cosmological/hydrodynamical volumes (e.g. CAMELS, IllustrisTNG). It renders the cube as an interactive, GPU-accelerated 3D volume built on PyVista and VTK.
